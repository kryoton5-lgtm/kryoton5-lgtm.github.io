04 / Working approach

Clarity before complexity.

A practical approach to well-specified computational tasks and useful technical feedback.

01 / FRAME

Define the problem.

State the scientific objective, inputs, assumptions, and expected outputs. Make the task self-contained.

02 / BUILD

Make it executable.

Choose appropriate methods, implement the workflow, and document the steps needed to reproduce it.

03 / CHECK

Evaluate the evidence.

Examine correctness, edge cases, physical or mathematical constraints, and meaningful failure modes.

04 / REFINE

Turn review into progress.

Use specific feedback to improve the task, clarify the explanation, and strengthen the final deliverable.

One principle: difficulty should come from the problem itself—not from missing information.
