## Experience the work

- **Generative mathematical sculpture:** switch among a computational field, a parametric knot, and a Lorenz attractor. Drag with a mouse to rotate the scene.
- **Selected project overviews:** filter and explore technical case studies in scientific modeling, LLM evaluation, and binary telemetry systems.
- **Interactive inverse-problem lab:** adjust a decay parameter and observation noise, then run a bounded numerical search to fit a model to synthetic observations. Computation happens entirely in the browser.
- **Technical expertise and working approach:** numerical methods, data analysis, machine learning, GenAI, structured evaluation, and mathematical documentation.
- **Accessible interaction:** keyboard navigation, a Ctrl/Cmd + K command palette, responsive mobile navigation, animation pause, and reduced-motion support.

## Run locally

No build step, framework, API key, or package installation is required.

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser. The website is a static HTML/CSS/JavaScript application. It uses system fonts, inline SVG icons, and no external analytics or tracking scripts.

## Scientific scope and confidentiality

The hero sculpture is generative geometry, not experimental data. The parameter-estimation lab is an educational demonstration using seeded synthetic observations; it is not a production reactor model or a research result.

Project descriptions are high-level summaries. Private source code, observations, canonical parameters, evaluation thresholds, and confidential authoring artifacts are not published in this repository. Project graphics are illustrative. No independently verified benchmark performance is claimed.
